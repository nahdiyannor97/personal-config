# UI Motion & Animation Skill

When this skill is activated, you must adhere to the motion design standards and animation rules defined for this project.

## Execution Instruction

Before creating, modifying, or refactoring any animated UI components:

1. Use the `view_file` tool to read the complete guidelines in `motion.md`.
2. Follow the performance constraints, duration timing, easing functions, and accessibility conventions specified in that file.
3. Ensure animations are smooth, purposeful, and do not hinder the user experience.
